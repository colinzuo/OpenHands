# Investigations

Where the real thinking happens. **One file per question / bug / idea.**

Naming: `YYYY-MM-DD-topic.md` (e.g. `2026-06-11-settings-401-in-sandbox.md`).

Suggested structure per file:
- **Question / symptom** — what I'm trying to understand or what's broken.
- **Observations** — facts, logs, repro steps.
- **Hypotheses** — ranked guesses.
- **What I tried** — and the result.
- **Resolution / next step** — outcome, or where I left off.

Pairs well with Claude: paste a section and ask
`Given this investigation, what would you try next?`
When a finding is durable, promote it into [020-architecture.md](../020-architecture.md) or [030-decisions.md](../030-decisions.md).
