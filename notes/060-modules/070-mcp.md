# mcp

`openhands/app_server/mcp/mcp_router.py`

## What it does
Exposes an **MCP (Model Context Protocol) server** that the app server mounts, giving agents in sandboxes a set of server-side tools. Built on `FastMCP`.

## Key facts
- `mcp_server = FastMCP('mcp', mask_error_details=True)` — the server instance, mounted in `app.py` via `mcp_server.http_app(path='/mcp', stateless_http=True)`.
- `init_tavily_proxy()` (called from `app.py` before app creation) mounts Tavily's hosted MCP server under the `tavily` namespace **only if `tavily_api_key` is configured**. Tools surface as `tavily_*`. Purpose: sandboxes get Tavily web search **without the API key ever being exposed to them** (the proxy holds the key).
- Server-side tools defined here with `@mcp_server.tool()`: e.g. `create_pr`, `create_mr` (open PRs/MRs), plus helpers like `get_conversation_link`, `save_pr_metadata`.

## Notes / gotchas
- `mask_error_details=True` — tool errors are masked to callers; check server logs for real causes.
- Tavily proxy is best-effort: failures are logged, not fatal (app still starts).
- The PR/MR creation tools are the bridge that lets an agent turn its work into an actual pull/merge request.
